## 💡 Conventions

### Comment lire ce tableau
- **ID** : Numéro de la tâche (lien vers dossier)
- **Statut** : 📝 To Start | 🟡 En cours | ✅ Terminée | ❌ Abandonnée
- **Priorité** : P0 (urgent) > P1 (important) > P2 (nice to have)
- **Effort** : Temps estimé pour compléter
- **Impact** : ⭐ (faible) à ⭐⭐⭐⭐⭐ (critique)
- **Deadline** : Date cible de complétion

### Workflow
1. Toujours commencer par les tâches P0
2. Une tâche 🟡 En cours max par personne
3. Mettre à jour `status.md` après chaque session
4. Compléter `results.md` quand tâche ✅ Terminée
