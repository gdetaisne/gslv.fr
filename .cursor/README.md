## 🚀 Quick Start

### Pour commencer une nouvelle session
1. Lire `tasks/README.md` → voir tâches prioritaires
2. Ouvrir la tâche P0 suivante (ex: `tasks/01-reputation-ligerio/task.md`)
3. Exécuter les actions décrites
4. Mettre à jour `status.md` avec timestamp + résultats
5. Passer à la tâche suivante

### Workflow hebdomadaire (vendredi)
1. Mettre à jour `status.md` de toutes les tâches en cours
2. Vérifier KPI dans Google Search Console
3. Mettre à jour `kpi-tracking.md`
4. Ajuster priorités dans `tasks/README.md` si nécessaire

### Workflow mensuel (1er du mois)
1. Compléter `results.md` des tâches terminées
2. Calculer ROI de chaque tâche
3. Mettre à jour `roadmap.md` (avancement)
4. Dashboard complet dans `kpi-tracking.md`
