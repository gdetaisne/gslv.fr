## Spécifications techniques :

- **Format** : PNG avec transparence
- **Taille** : 200x200px minimum
- **Poids** : < 100KB par image
- **Style** : Logo officiel de l'entreprise

## Fallback :

Si un logo n'est pas disponible, un icône générique (🏢) s'affichera automatiquement.
