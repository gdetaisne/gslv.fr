# Images du carrousel de la page d'accueil

Ce dossier contient les images qui s'affichent dans le carrousel au niveau du titre de la page d'accueil.

## Spécifications techniques :

- **Format** : JPG, PNG ou WebP
- **Taille recommandée** : 1920x1080px (16:9)
- **Poids** : < 500KB par image pour un chargement rapide
- **Style** : Images professionnelles, modernes, en rapport avec le business

## Suggestions d'images :

- Bureaux modernes
- Équipes en réunion
- Graphiques de croissance
- Technologies financières
- Startups en action
- Tableaux de bord
- Levées de fonds
- Restructuration d'entreprises

## Nommage des fichiers :

- `carousel-1.jpg`
- `carousel-2.jpg`
- `carousel-3.jpg`
- etc.

Le carrousel affichera automatiquement toutes les images présentes dans ce dossier.
